# Ravula Akshitha | AI & ML Engineer Portfolio

A premium, interactive developer portfolio built with modern front-end technologies featuring rich aesthetics, glassmorphic elements, smooth custom cursor effects, and subtle animations.

---

## ✨ Features

- 🌟 **Modern Glassmorphic Design:** Sleek dark-mode aesthetic with harmonized HSL color gradients (Violet & Cyan).
- ✍️ **Dynamic Typing Animation:** Custom JavaScript typing loop showcasing expertise areas (ML Models, AI Solutions, Deep Learning).
- 🖱️ **Interactive Cursor Trail:** A smooth cursor glow backdrop and custom cursor dot tracker that dynamically scale on hover.
- ⚛️ **Connected Particle Background:** Live HTML5 Canvas physics-based particle connections reacting to viewport resize.
- ⚡ **Animated Stats & Progress:** Smooth cubic-ease-out numerical counters and progress bar loading states triggered when scrolling into view.
- 📱 **Fully Responsive:** Fluid layouts designed to look stunning on mobile, tablet, and desktop screens.
- 📧 **Direct Connect Card:** Direct links to LinkedIn, Email, Phone, and GitHub for easy access.

---

## 🛠️ Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Custom Vanilla CSS3 (Custom design tokens, CSS variables, keyframe animations)
- **Logic:** Vanilla ES6+ JavaScript
- **Typography:** Google Fonts (Inter & Fira Code)

## 🚀 How to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/ravulaakshitha2006-source/MYPORTFOLIO.git
   cd MYPORTFOLIO
   ```

2. **Start a Local Server:**
   You can serve the directory using any static web server:
   
   - **Using Node.js (`http-server`):**
     ```bash
     npx http-server -p 3000
     ```
   
   - **Using Python:**
     ```bash
     python -m http.server 3000
     ```

3. **Open in Browser:**
   Navigate to `http://localhost:3000` to view the running page.
